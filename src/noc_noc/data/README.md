# job_bank_2026_07_09.tsv

4,242 job titles as employers wrote them, each with the NOC 2021 code its posting was filed under. Derived
from *Job Postings Advertised on Canada's National Job Bank Website*, July to September 2026, by
Employment and Social Development Canada. Contains information licensed under the
[Open Government Licence – Canada](https://open.canada.ca/en/open-government-licence-canada).

Rebuild with `noc-noc build-job-bank <monthly CSV files…>`. See `docs/benchmark.md` for the filters.
